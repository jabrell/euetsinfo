# Data processing

Processing is done in four major steps that build one on another:

1. **Download** Download of the EUTL data from the [EUTL Webpage](https://union-registry-data.ec.europa.eu/report/welcome)
2. **Normalization** In this step, column names are normalized and unique identifiers for accounts and installations are introduced.
3. **Extraction** We extract the basic tables from the EUTL data.
