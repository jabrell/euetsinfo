# Legacy Data

This page provides access to data and material previously provided at the
EUETS.INFO webpage. You can use them freely but please cite the repository
as data source.

## Documentation and Notes

- [A short note on transaction data](https://euets-info-public.s3.eu-central-1.amazonaws.com/Abrell_2024_eutl_transactions.pdf) — notes on the structure and caveats of transaction data
