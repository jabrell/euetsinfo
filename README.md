# euetsinfo

## Project Management

### Clone the Repository

```bash
git clone https://github.com/jabrell/euetsinfo.git
cd euetsinfo
```

### Install with uv

This project uses [uv](https://docs.astral.sh/uv/) for fast and reliable Python
package management.

First, install uv if you haven't already. Then install the project dependencies:

```bash
uv sync
```
