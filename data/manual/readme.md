This folder contains data files that are downloaded/created manually elsewhere.

## Sources and Files

### Leakage and NACE codes
- **leakage_2020.xlsx**: NACE codes for installations from the 2020 preliminary assessment https://ec.europa.eu/clima/events/stakeholder-meeting-results-preliminary-carbon-leakage-list-phase-4-eu-emissions-trading_en
- **leakage_2015.xlsx**: NACE codes from 2015 leakage classification of EC https://climate.ec.europa.eu/document/download/56c44a4d-141d-4beb-8bdf-e0f7bed0dfa3_en?filename=installation_nace_rev2_matching_en.xls
- **NACE_REV2_20200427_154248.htm**: The NACE classification itself is downloaded from Eurostat RAMON: https://ec.europa.eu/eurostat/ramon/nomenclatures/index.cfm?TargetUrl=LST_CLS_DLD&StrNom=NACE_REV2&StrLanguageCode=EN&StrLayoutCode=HIERARCHIC#

### Registry Data
This folder also contains data that have been manually downloaded from the [PowerBi app](https://union-registry-data.ec.europa.eu/report/welcome). As a general rule, be
careful with the manual downloads in checking:

1. No filters are applied
2. The download restriction (150'000) rows do not affect the download.

- **accounts.xlsx** Accounts downloaded from *Emission Trading System -> Accounts*
- **operator_accounts.xlsx** Operator accounts downloaded from *Emission Trading System -> Operator Accounts*
