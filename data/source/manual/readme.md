This folder contains data that have been manually downloaded from the [PowerBi app](https://union-registry-data.ec.europa.eu/report/welcome). As a general rule, be
careful with the manual downloads in checking:

1. No filters are applied
2. The download restriction (150'000) rows do not affect the download.


## File list

- **accounts.xlsx** Accounts downloaded from *Emission Trading System -> Accounts*
- **operator_accounts.xlsx** Operator accounts downloaded from *Emission Trading System -> Operator Accounts*
